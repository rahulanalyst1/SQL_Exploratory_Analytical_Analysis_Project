# SQL Exploratory & Analytical Analysis

## 📌 Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) and advanced analytical analysis using Microsoft SQL Server. The objective is to explore the dataset, understand its structure, examine key business metrics, and identify patterns and trends through SQL queries.

The project covers database exploration, data analysis, ranking, trend analysis, cumulative calculations, performance analysis, and data segmentation.

## 🎯 Project Objectives

- Understand the database structure and explore its dimensions and measures.
- Examine date ranges and identify key metrics within the dataset.
- Analyze data distributions, rankings, and performance patterns.
- Track changes in metrics over time.
- Perform cumulative and part-to-whole analysis.
- Segment data to examine patterns across different categories.

## 🛠️ Tools & Technologies

- **Microsoft SQL Server** – Database management and SQL analysis.
- **SQL Server Management Studio (SSMS)** – Writing and executing SQL queries.
- **SQL** – Data exploration, transformation, aggregation, and analysis.

## 💡 SQL Concepts Applied

- **Query Structure:** SELECT, WHERE, ORDER BY, GROUP BY, HAVING
- **Joins:** INNER JOIN, LEFT JOIN, and other relevant joins
- **CTEs & Subqueries:** Organizing complex queries and breaking down analysis
- **Window Functions:** RANK(), DENSE_RANK(), ROW_NUMBER()
- **Aggregate Functions:** SUM(), AVG(), COUNT(), MIN(), MAX()
- **Conditional Logic:** CASE WHEN
- **Date Functions:** Date extraction and date-based calculations
- **String Functions:** Text manipulation and data exploration
